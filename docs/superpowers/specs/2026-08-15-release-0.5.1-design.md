# `@pi-vault/pi-tools` 0.5.1 release prep

**Status:** approved
**Date:** 2026-08-15
**Scope:** documentation-only release

## Purpose

Prepare a `0.5.1` patch release of `@pi-vault/pi-tools`. The release rolls up
changes that landed after `0.5.0` was tagged on 2026-07-21:

- TinyFish Search and Fetch provider (added 2026-08-12, after `0.5.0`).
- Five architecture-deepening refactor phases (PRs #105–#109).
- A dependency update commit and a Biome schema bump to `2.5.8`.

No new public API surface; no source-code changes in this release.

## Version

`0.5.0` → `0.5.1` (patch: refactors + dep refresh + one newly public
provider, no breaking changes).

## Files changed

Three files. No source code edits.

### 1. `package.json`

Change `"version": "0.5.0"` to `"version": "0.5.1"`. Nothing else.

### 2. `CHANGELOG.md`

1. **Remove** the TinyFish line from `[0.5.0]`. TinyFish was added after
   `0.5.0` was tagged and currently sits in both `[0.5.0]` and `[Unreleased]`.
   The line belongs in `0.5.1`, not `0.5.0`.
2. **Replace** `[Unreleased]` with a new `## [0.5.1] - 2026-08-15` section
   grouped under `### Added` and `### Changed`:
   - **Added** — TinyFish Search and Fetch provider support through
     `TINYFISH_API_KEY`.
   - **Changed** — Internal architecture deepening across five phases:
     search filter enforcement, provider catalog centralization, unified
     provider operation policy, runtime lifecycle alignment, and content
     extraction fallback seam. Biome schema upgraded to `2.5.8`. No public
     API changes.
3. Add an Unreleased-comparison link consistent with the existing pattern
   (`[0.5.1]: ...`) at the bottom of the file.

### 3. `README.md`

Replace the existing `## What's new in 0.5.0` callout block with a
`## What's new in 0.5.1` block. Two short bullets:

- TinyFish provider added — `TINYFISH_API_KEY` enables keyless search and
  fetch.
- Internal architecture deepened for filter enforcement, provider catalog,
  operation policy, runtime lifecycle, and extraction fallback — no public
  API changes.

The rest of the README is unchanged. The TinyFish row already exists in the
provider table from the work that landed post-`0.5.0`; no table edits needed.
